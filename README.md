# GlassDesign by GIP – versiuni

Aici se publică versiunile gata de instalat ale programului **GlassDesign by GIP** (program de proiectare și ofertare pentru produse din sticlă, GIP SRL Craiova).

Depozitul este public și conține doar fișierele de instalare și notele fiecărei versiuni. Codul sursă este într-un depozit privat.

## Cum instalezi

1. Deschide pagina **Versiuni** (Releases) a acestui depozit.
2. Descarcă cea mai nouă versiune pentru Windows (fișierul `.exe`).
3. Rulează-l. Instalarea se face pentru utilizatorul curent și nu cere drepturi de administrator.

Programul este numai în limba română.

## Stadiul de acum

Versiunea locală pentru pilotul de Duș este în lucru. Prima versiune va apărea aici când este gata de încercat.
